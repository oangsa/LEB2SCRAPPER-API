# Security policy

## Reporting a security problem

Report non-confidential security problems through the public
[GitHub Issues page](https://github.com/oangsa/LEB2SCRAPPER-API/issues/new).

GitHub Issues are public. This project offers no private security-reporting
channel. Do not include credentials, session cookies, authorization headers,
passwords, private keys, user or assignment data, raw sensitive logs, or
exploit details that require confidentiality. Redact and minimize any
proof-of-concept information before filing an issue.

This policy does not promise issue availability, monitoring, response times,
or confidentiality.
